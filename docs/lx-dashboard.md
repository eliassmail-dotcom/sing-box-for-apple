# sing-box lx++ — Dashboard / «Режим»

## Поведение

Главная карточка «Режим» объединяет выбор стратегии и отображение текущего
маршрута. «Авто • Умный» расположен первым и занимает всю ширину;
четыре остальные плитки — ниже в две колонки.

- **Авто • Базовая**, **Авто • Белые**, **Авто • Полная** и **Ручной режим**:
  зелёная цифра — число *уникальных* узлов выбранной группы, имеющих
  положительный результат URLTest. Вложенные selector/urltest-группы не
  считаются узлами.
- **Авто • Умный**: два счётчика — «Базовые» и «Белые» — отдельно.
  Суммировать их нельзя: узлы могут пересекаться, а белые находятся
  в резерве, пока отвечает хотя бы один базовый.
- Режимы активируются нажатием плитки; синяя рамка отражает **живое**
  состояние селектора `Стратегия` и, при наличии, `Gemini`.
  При ручном изменении одного из селекторов может появляться
  «Смешанная конфигурация».
- Режим «Авто • Умный» доступен автоматически, если профиль содержит
  подходящие группы Базовая, Белые и селектор Стратегия.
  Дополнительного переключателя в настройках LX нет.
  Само наличие резервной группы не включает резервирование:
  оно действует только при выборе этого режима.

## Повторное нажатие: «Сменить узел»

- Нажатие на неактивный режим **выбирает стратегию**, как раньше.
- Нажатие на **уже активный** режим вызывает «Сменить узел»:
  подбирается следующий доступный узел внутри текущей стратегии.
  Текущие селекторы `Стратегия` и `Gemini` не переключаются.
- `Авто • Умный`: команда направляется корневой URLTest-группе,
  которая рекурсивно меняет конечный узел только в выбранной приоритетной
  группе. Пока базовые доступны, в белые переходить **нельзя**.
- `least_test` / `failover`: ядро циклически выбирает следующий узел
  из ответивших на URLTest; стабильный порядок — штрафы, задержка, тег.
  Новый выбор удерживается минимум 30 секунд, если узел остаётся здоров.
  Реальные ошибки и переходы base→white→base обходят это удержание.
- `Ручной режим`: следующий доступный узел выбирается внутри селектора
  `Ручной выбор`, не меняя `Стратегия`.
- `round_robin`: единый узел отсутствует (маршрут выбирается для каждого
  соединения), поэтому команда **явно отклоняется**, а не имитирует
  переключение. Доступность и ошибку показывает интерфейс.
- Если другого живого узла нет, прежний маршрут сохраняется и
  показывается предупреждение. Уже существующие соединения не разрываются.
- Команда использует старый `SelectOutbound` RPC с зарезервированным
  `outboundTag = "__lx_next_node__"` только для URLTest-групп LX,
  что не меняет формат подписки или proto. Нужна соответствующая версия ядра.


## Текущий маршрут

Под плитками всегда есть блок «Основной маршрут» и, если профиль содержит
селектор Gemini, строка «Gemini». Они показывают выбранный ядром маршрут,
а не выводят результат случайного speedtest или IP-check:

1. `CommandClient.groups` передаёт живое состояние селекторов/urltest.
2. `GetRunningConfig` по возможности даёт граф outbounds, включая detour.
3. `SelectedOutboundResolver` проходит вложенные группы до выбранного
   конечного узла; для Gemini показывает доступную цепочку `вход → выход`.
4. Пока running config не получен, строится временный граф по живым
   группам *включая листья* (без информации о detour).
5. Подписка на данные запускается при появлении всей карточки, даже если
   информация о выбранном узле ещё не получена.

При использовании Round Robin выбор может зависеть от конкретного
соединения. Отображаемое значение — выбранный/сообщаемый ядром узел
группы, не гарантия, что каждый отдельный поток идёт ровно через него.

## Сохранённые пользовательские настройки

Старые dashboard-карточки `strategyNode` и `geminiNode` удалены
из списка карточек. Если одна из них ранее была включена, а карточка
`strategyMode` — нет, видимость переносится на объединённую карточку.
Порядок прочих dashboard-карточек сохраняется.

## Проверка

- Открыть Dashboard после запуска VPN: названия узлов и пинги должны
  появляться без открытия старых отдельных карточек.
- Изменить основной режим и выбор Gemini в Groups: живой маршрут
  должен обновиться без перезапуска приложения.
- Проверить nested URLTest, ручной выбор, Gemini detour chain,
  отсутствие селектора Gemini, гостевой профиль и неработающие URLTest.
- Проверить миграцию dashboard-видимости со старой версии.
- Проверить повторное нажатие во всех пяти режимах: базовые/белые/полная,
  приоритетная Smart-группа, ручной селектор. Gemini остаётся прежним.
- Проверить 30-секундное удержание, переключение при отказе, отсутствие
  здоровых альтернатив и честную ошибку для Round Robin.
