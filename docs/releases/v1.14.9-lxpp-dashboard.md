# sing-box lx++ 1.14.9 — Dashboard refresh

## Dashboard
- Added a compact live-routes card with the primary route on the left and Gemini on the right.
- Gemini chains are indicated only by a link icon; the displayed country is the final exit node.
- Moved live route information above mode selection and placed profile configuration at the end of the default Dashboard order.
- Tightened card spacing and control heights.
- Corrected the selected resilience preset so it remains visually active instead of appearing disabled.
- Increased the fallback scroll-content inset so the floating connection accessory does not cover the final card.
- Localized the main navigation and visible Dashboard headings into Russian.

## Build 12 — vertical routes
- Replaced the two-column routes grid with two full-width rows within the same card.
- Primary route comes first and Gemini second; the chain icon appears only for a chained Gemini route.
- Route names retain the original outbound tags exactly, including all qualifiers and suffixes.
- Latency is aligned at the right of each route; long names may wrap, never middle-truncate.
- No changes to the VPN core or routing rules.

## Compatibility
- Preserved the existing strategy, Gemini, URLTest, resilience and profile-selection behavior.
- Added unit coverage for final-node presentation in native and detour-based chains.
- App display name remains `sing-box lx++`.
